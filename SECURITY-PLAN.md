# RentHub AI Security Assessment

## 1. Project Overview

RentHub AI is an apartment management system developed using ReactJS, Java Spring Boot, and MySQL.

## 2. Security Assessment Scope

- Authentication and authorization.
- Admin and User access control.
- Apartment ownership verification.
- Contract and invoice access control.
- SQL Injection testing.

## 3. Assessment Objectives

- Identify potential security vulnerabilities.
- Perform security testing on existing APIs.
- Implement appropriate security controls.
- Verify security improvements after remediation.
